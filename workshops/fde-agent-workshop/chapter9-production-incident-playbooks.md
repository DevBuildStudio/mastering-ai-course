# Chapter 9: Production Incident Playbooks

## Why This Chapter Matters
When incidents happen, response speed and clarity matter more than perfect diagnosis in the first minutes.

## Learning Objectives
- Classify AI incidents by source and severity.
- Execute first-response mitigation safely.
- Communicate impact and status clearly.

## Core Concepts
- Incident classes: model, retrieval, tool, infra.
- Detection signals and leading indicators.
- Rollback and degradation modes.
- Post-incident review structure.

## Practical Framework
First 30 minutes of incident response:
1. Confirm impact and blast radius.
2. Switch to safe fallback mode.
3. Collect minimal diagnostic evidence.
4. Communicate status and ETA updates.

## Exercise
Run a tabletop simulation:
- Retrieval drift causes incorrect policy answers.
- Tool API starts timing out.
- Confidence score drops across traffic.

## Output
An operational playbook with triggers, owners, and run steps.
